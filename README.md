A simple game project created \*\*for learning and experimentation purposes\*\* using \*\*Visual Studio\*\*, \*\*WinUI\*\*, \*\*XAML\*\*, and \*\*C#\*\*.



This project was developed while exploring game development concepts and modern Windows application development, with assistance from \*\*OpenCode CLI\*\* and the \*\*Muse1.3 model\*\*.



> 🚧 This is a learning project and is not intended to be a production-ready game.



\## 🧠 Purpose



The main goal of this project is to learn and experiment with:



\* 🎮 Basic game development concepts

\* 🪟 Windows UI development with WinUI

\* 🎨 UI design using XAML

\* 💻 C# programming

\* 🔄 Game logic and application flow

\* 🧩 Working with Visual Studio

\* 🤖 Using AI-assisted development tools

\* 🛠️ Exploring OpenCode CLI with the Muse1.3 model



\## 🛠️ Technologies Used



\* \*\*Language:\*\* C#

\* \*\*UI:\*\* XAML

\* \*\*Framework:\*\* WinUI

\* \*\*IDE:\*\* Visual Studio

\* \*\*AI Development Tool:\*\* OpenCode CLI

\* \*\*AI Model:\*\* Muse1.3



\## 🤖 AI-Assisted Development



This project was created as an experiment in \*\*AI-assisted software development\*\*.



I used \*\*OpenCode CLI\*\* with the \*\*Muse1.3 model\*\* to help with development, experimentation, debugging, and learning different implementation approaches.



The purpose was not simply to generate the project, but to use AI as a learning and development companion while understanding how the code and different components work.



\## 📚 Learning Goals



Through this project, I am learning about:



1\. C# application development

2\. WinUI and XAML

3\. Event handling and user interaction

4\. Game logic

5\. UI and game-state management

6\. Debugging and testing

7\. Structuring a small application

8\. Using AI tools effectively during development
